SysKline 首个公开版本：在纯终端内，以金融 OHLC K 线观察系统资源变化。

- macOS、Linux、Windows 原生采集；每个系统提供 amd64 / arm64 单文件可执行程序，无需 Go、CGO 或外部数据库服务。
- 默认综合总览：CPU、内存、磁盘 I/O、网络、Swap、负载六区，支持终端尺寸自适应和单指标大图。
- 1s / 5s / 15s / 1m / 5m / 15m / 1h / 1d 周期，真实实体与影线、OHLC、MA5、十字光标、历史滚动、缩放、折线切换。
- SQLite 历史持久化、分钟聚合、自动清理；TOML 配置、ASCII 降级、可自定义配色。
- 三系统原生 CI 检查；六目标发布包验证架构、内容和 SHA256 校验和。

**下载：** Intel / AMD 选择 amd64；Apple Silicon / ARM 选择 arm64。
macOS / Linux 下载对应 `.tar.gz`，解压后运行 `./syskline`；Windows 下载 `.zip`，解压后运行 `syskline.exe`。
也可直接下载原始单文件，Unix 系统需添加执行权限。每个安装包附带 README、MIT 许可证和配置示例。

`SHA256SUMS` 覆盖六个二进制及六个安装包。仅在程序运行期间记录历史。
Windows 不提供 Unix 负载均值，对应三项显示 `n/a`；无法读取的可选计数器也显示 `n/a`。
