# SysKline Implementation Plan

> **For agentic workers:** Execute inline, task by task, using TDD for substantive behavior.

**Goal:** Deliver a usable Linux metrics trading terminal with durable history.

**Architecture:** Separate metrics/collection, SQLite storage, chart rendering,
configuration, and Bubble Tea interaction. Commands perform sampling/storage away
from rendering; UI history queries stay bounded and serialized with each sample.

**Tech Stack:** Go, Bubble Tea v1, Lip Gloss v1, modernc SQLite, TOML v2.

**Spec:** `docs/superpowers/specs/2026-11-02-syskline-design.md`

## Global Constraints

- Linux amd64/arm64, CGO_ENABLED=0 single binary; no browser or server.
- 1 second default sampling, 7 days raw and 90 days minute OHLC retention.
- UTC bucket alignment, actual samples only, no invented historical points.
- Default dark theme with red increases and green decreases; ASCII fallback.

## Review Focus

- Counter reset / device hotplug must not create artificial traffic spikes.
- Retention must preserve longer OHLC history and actually free database pages.
- A terminal smaller than the preferred dimensions must never overflow.
- History, cursor and paused viewport must remain stable as samples arrive.
- Errors must remain visible and must not kill keyboard responsiveness.
